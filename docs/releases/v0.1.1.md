# v0.1.1 — ZoomPan

Maintenance release focused on installer usability, removal, and safer validation.

## Changes

- Added integrated uninstall to the same `VLCZoomPanSetup.exe`.
- Uninstall removes the plugin, removes `zoompan` from `extraintf`, restores ZoomPan-related VLC settings from the pre-install backup when available, and refreshes the VLC plugin cache.
- Added an obvious direct installer download link to the README.
- Installer now enforces the validated VLC 3.0.21 x64 target instead of accepting arbitrary VLC 3.x installations.
- CI validates the generated PowerShell installer script syntax before compiling the setup executable.

## Install

Download `VLCZoomPanSetup.exe`, run it as administrator, select the folder containing `vlc.exe`, and choose install/update.

## Uninstall

Close VLC, run the same `VLCZoomPanSetup.exe` again, select the VLC folder, and choose uninstall.

## Validated environment

- VLC 3.0.21
- Windows x64

## Files

- `VLCZoomPanSetup.exe` — recommended installer and uninstaller
- `libzoompan_plugin.dll` — raw plugin for advanced/manual installation
- `SHA256SUMS.txt` — release checksums

The executable is not digitally signed, so Windows SmartScreen may show an unknown-publisher warning.
