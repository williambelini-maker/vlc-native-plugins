# v0.1.0 — ZoomPan

First public release of ZoomPan.

## Features

- Ctrl + mouse wheel zoom through VLC's native scale-factor controls.
- Left-button drag to pan enlarged video.
- Middle-button double-click to reset and fit.
- Native VLC interface module running inside `vlc.exe`.
- No background helper, service, startup process, or custom launcher.
- Single-file Windows installer.

## Validated environment

- VLC 3.0.21
- Windows x64

## Files

- `VLCZoomPanSetup.exe` — recommended installer
- `libzoompan_plugin.dll` — raw plugin for advanced/manual installation
- `SHA256SUMS.txt` — release checksums
