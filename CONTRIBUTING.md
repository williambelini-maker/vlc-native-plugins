# Contributing

Keep plugins small, native, auditable, and version-tested.

A contribution should include:

- exact VLC version(s) tested;
- Windows architecture;
- a concise manual test checklist;
- source changes required to reproduce the behavior;
- no unnecessary background process or startup component when an in-process VLC module can do the job.

Do not describe community modules as official VideoLAN plugins unless VideoLAN explicitly says so.
